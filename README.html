Bring Your Own Key (BYOK) — getting started

This guide walks you through encrypting your Cortex tenant with a key that you create and control. You will do part of the work in Cortex Gateway, and part on your own computer.

In plain words

With BYOK, Cortex still runs your tenant in Palo Alto Networks’ cloud — but the master encryption key (your target key) comes from you, not from the default platform key.

Your tenant needs encryption for two areas: the Data lake and other Services. You can use one key for both areas, or create two different keys. Most customers start with one key for both.

What you create vs what Cortex gives you You create the secret 32-byte key. Cortex Gateway gives you temporary wrapping keys (public files ending in .pem). Those wrapping keys only protect your secret while you upload it — they are not your BYOK key.
ItemWhoWhat to do with it
Your target key (targetkey) You Create it once. Store it safely. Never upload this file as-is.
Wrapping keys (.pem) Gateway Download from the wizard (Data lake + Services). Valid for up to 3 days.
Wrapped key files Upload Created by the wrap script. Upload these in Gateway to finish.

Step-by-step

  1. Start BYOK in Cortex Gateway

    Sign in to Cortex Gateway and activate your tenant. Under Advanced, choose BYOK (Bring Your Own Keys), then Create Tenant and Set Up Keys.

    Initialization can take a few minutes. If you pause, you can continue later with Set Up Encryption Keys next to the tenant.

  2. Create your secret key (on your computer)

    On the Generate Key screen, create a 32-byte encryption key. The easiest way with this package: 

    ./run-byok.sh generate targetkey

    Then tick I have a 32-byte symmetric encryption key ready and continue.

    Keep this file safe Treat targetkey like a password vault root key. Back it up offline. Do not email it, commit it to git, or upload it unwrapped.

  3. Download the wrapping keys from Gateway

    On the Wrap & Upload screen you will do this twice — once for Data lake and once for Services.

    Choose the import method RSA_OAEP_3072_SHA256_AES_256 (recommended default), then download each wrapping key (.pem file).

    Wrapping keys expire after 3 days. If they expire, download new ones.

  4. Wrap your secret key

    Wrapping packages your secret so it can travel safely into Cortex. Place both downloaded .pem files next to the script, then run: 

    ./run-byok.sh wrap-both \
  datalake_wrapping_key.pem \
  services_wrapping_key.pem \
  targetkey \
  ./out

    This creates two files ready to upload: out/datalakewrappedkey and out/serviceswrappedkey.

    First-time setup needs a patched OpenSSL at $HOME/local/bin/openssl.sh (required by the default import method).

  5. Upload and finish

    Back in Gateway, upload the Data lake wrapped file, then the Services wrapped file. Click Complete Activation.

    When activation finishes, your key becomes the primary key for new data stored in the tenant.
